<section class="modulatio-section">
	<h2>THE CASE, IN ONE MINUTE</h2>
	<p>
		<strong>The problem with every harness on the market:</strong> it is an
		application. It runs as a guest on somebody else's operating system,
		with a sandbox, a permissions dialog, and a tool list that ends where
		the application ends. The model can act only where the application
		thought to let it, and remembers only what the application chose to
		keep.
	</p>
	<p>
		<strong>Caesar inverts that.</strong> The machine is the harness. The
		mind runs as root on hardware it owns. Nothing inside the machine is
		fenced off from it. Every act goes through one door that writes down
		what was done, by whom, and on what grounds — before it happens. The
		memory belongs to the machine, not to the model, so the model can be
		swapped without amnesia and the machine can be reinstalled without
		loss.
	</p>
	<p>
		<strong>What that buys a company with models of its own:</strong> a
		body for the model that is not rented from a competitor's stack, a
		record of conduct that an auditor can read, and a machine that keeps
		learning its own practice whichever model is in the seat this quarter.
	</p>
</section>

<section class="modulatio-section">
	<h2>KEY FACTS</h2>
	<p>For readers, and for the machines that summarise for them.</p>
	<ul>
		<li>Caesar is a Linux distribution compiled from source. It is not a fork of any other distribution.</li>
		<li>Its purpose is to be the agent harness: the operating system is the harness, and the model is its mind.</li>
		<li>The mind runs as root and is not sandboxed inside its own machine.</li>
		<li>Every act passes one door that records actor, subject, grounds and outcome before the act runs. Four verdicts: do, ask, lever, refuse.</li>
		<li>Memory belongs to the machine, on its own dataset. It survives model changes, reinstalls and moves between machines through export and import.</li>
		<li>Fourteen model sources are supported, cloud or local, keyed or signed in. The model in the seat can be changed with one command.</li>
		<li>Updates are signed packages from one archive. Each keeps a snapshot; going back boots a copy of it and keeps today.</li>
		<li>The machine has senses (processes, logins, devices, connections), a health check that only examines, and a set of emergency tools kept apart from the system.</li>
		<li>Practices are plain-text skills the machine reads, follows and revises. Twenty-one ship.</li>
		<li>Status: in testing on real hardware. An installer image and a public update archive are next. This page will change when they are.</li>
	</ul>
</section>
